# Brújula Viajes

Sitio web de una agencia de viajes por Colombia. Proyecto integrador de Ingeniería Web I.

## Qué incluye

- Portada con buscador de planes tipo pase de embarque
- Seis destinos con filtro por tipo de plan y detalle desplegable
- Tres paquetes (Esencial, Confort, Premium)
- Cotizador con valor estimado según destino, paquete, adultos y niños
- Preguntas frecuentes y formulario de contacto con validación
- Diseño responsivo para computador, tableta y teléfono móvil

## Cómo abrirlo

No necesita instalación. Abre `index.html` en un navegador.
Las tipografías se cargan desde Google Fonts; sin internet se usan fuentes del sistema.

## Estructura

```
index.html          Página principal
css/styles.css      Estilos (variables, componentes, responsivo)
js/main.js          Menú móvil, filtro, cotizador y validación
img/                Ilustraciones SVG
evidencias/         Capturas en computador, tableta y móvil
Documentacion_Brujula_Viajes.pdf   Documento de documentación
```

## Tecnologías

HTML5 semántico, CSS3 (Flexbox, Grid, media queries), JavaScript sin librerías.

Los precios, el teléfono y el correo son ficticios.
